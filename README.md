# plantism

a storybook garden theme for discord. night garden in dark mode, sunlit meadow in light mode.

## install

download `plantism.theme.css` and drop it in your themes folder (Equicord, Vencord or BetterDiscord), then enable it.

## assets

hand-drawn art lives in `assets/` as PNGs, with the SVG sources in `assets/src/`.
